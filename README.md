# medscan
MedScan v0.1. A.I. Biotech, First Product. A prototype AI-powered skin analyzer built for rapid risk assessment. What It Does: Upload a photo of a skin condition. MedScan analyzes: - Symmetry: irregular shapes get flagged - Border irregularity: uneven edges = higher risk - Color variation: multiple tones signal concern. Outputs a verdict: Likely Benign, Monitor, or See a Doctor. Disclaimer: This is a PROTOTYPE. Not a medical device. Not FDA approved. Always consult a real doctor. Tech Stack: Python, OpenCV (image analysis), Gradio (web interface), Google Colab (prototyping environment). Try It: Run the notebook in Google Colab or deploy locally: git clone https://github.com/aiindustries0/medscan.git, cd medscan, pip install -r requirements.txt, python app.py.
